# 📊 Pesquisa de Satisfação

Programa desenvolvido em **Python** para realizar uma pesquisa de satisfação com **50 entrevistados**, coletando nome, idade e opinião sobre o atendimento prestado, fazedo-se o uso da validaçao do campo do nome e usuário para garantir que os dados estão preenchidos corretamente.

O sistema classifica as respostas em:

* ⭐ **1 — Excelente**
* 👍 **2 — Bom**
* 👎 **3 — Ruim**

Ao final da pesquisa, o programa apresenta a quantidade de avaliações **Excelente**, **Bom** e **Ruim**.

## ⚙️ Funcionamento

O programa realiza o seguinte fluxo:

```text
Início
  ↓
Solicita nome, idade e opinião
  ↓
Valida os dados
  ↓
Registra a avaliação
  ↓
Repete até completar 50 entrevistados
  ↓
Exibe quantidade de "Excelente" e "Ruim"
  ↓
Fim
```
